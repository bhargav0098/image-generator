# Modern Professional Portfolio

A high-performance, visually stunning 3D portfolio website built with modern web technologies. This site features a sleek "Bento Box" grid layout, smooth animations, and a fully functional contact system.

## 🚀 Live Demo
Check out the live version here: [bhargav0098.github.io/image-generator](https://bhargav0098.github.io/image-generator)

## ✨ Key Features
- **Modern Bento Grid Layout**: Organized and visually appealing UI using Tailwind CSS.
- **Dynamic Certifications**: 8 individual certification cards with hover effects and direct links to credentials.
- **Functional Contact Form**: Integrated with FormSubmit.co using AJAX for a seamless "no-redirect" user experience.
- **Glassmorphism Design**: Premium glass-effect cards and HSL-tailored color palettes.
- **Responsive Animations**: Smooth reveal animations powered by the AOS (Animate On Scroll) library.
- **Fully Responsive**: Optimized for all devices, from mobile phones to high-resolution desktops.

## 🛠️ Tech Stack
- **Structure**: HTML5 Semantic Elements
- **Styling**: Tailwind CSS (Utility-first CSS)
- **Animations**: AOS.js & Custom Keyframe Animations
- **Contact Handling**: FormSubmit.co (AJAX implementation)
- **Icons/Visuals**: Emoji-based accents & Font Awesome

## 📁 Project Structure
- `index.html`: Main structure and content.
- `style.css`: Custom styling and theme definitions.
- `script.js`: Interactive elements and form handling logic.
- `assests/`: Images and static media.
- `certifiacete/`: Digital certificates and credentials.

## ⚙️ Setup & Deployment
To run this project locally:
1. Clone the repository.
2. Use a local server (e.g., Python or Live Server).
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
